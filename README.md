# QQ 群聊（qq/group）

独立的 QQ 群聊接入插件：与 `qq` 私聊插件共用同一个已登录的 QQ 账号，但拥有自己的群白名单、模式、人格/权限和设置页。每个群还可以单独指定人格；同一个人格的群共用一个渠道，会话仍按群分开。

> **安装位置固定为 `plugins/qq/sub/group`，不要解到 `plugins/group`。**
>
> 父插件必须是提供群接口的 QQ：官方 **0.24.0**（候选版起，官方包已声明 `sub: [qzone, group]`，无需手改父插件清单）或本地改版 **0.22.4**（`groupApiVersion: "1.0.0"`）。官方 0.23.0 及更早版本没有群接口，装上也不会启动。若使用本地 0.22.4 改版，仍确认 `sub: [qzone, group]` 后重载 QQ 主插件。
>
> 设置页若显示 `scope=missing`，表示父插件没有收到群授权范围；请升级到当前群聊子插件并重载 QQ 插件。

## 发行包

- [qq-group-0.6.8-win32-x64.wlpkg.gz](https://github.com/FelixTaXk/whalelife-community-qq-group/releases/download/v0.6.8/qq-group-0.6.8-win32-x64.wlpkg.gz)
- SHA-256 以 Release 页展示为准
- 适用：WhaleLife `0.1.1`，Windows `x64`，父插件 `qq` `0.24.0`（官方候选/正式版）；本地改版 `0.22.4` 也可运行

## 启用

1. 在插件页打开 `QQ 群聊` 的设置（`/plugins/qq/group/settings`）。
2. 勾选“启用群聊插件”，选好默认人格与群内工具权限。
3. 点“读取群列表”，用每行的 `@回复` / `主动` 按钮把群加进规则，在“人格”列可以直接给这个群选人格；也可以直接手写（`@人格ID` 省略时用默认人格）：

```
123456789 mention
987654321 active 家人群 @whale
```

4. 保存。未加入规则的群完全不处理（不会回复、不会记录、不会主动发言）。

## 每个群的人格

- 群规则可以带一个 `@人格ID`（设置页“人格”列的下拉框会帮你写进规则），例如 `987654321 active 家人群 @whale`。
- 省略时用“人格”下拉框里的默认人格；默认人格的群使用原来的 `qq-group` 渠道，升级前后会话不受影响。
- 其他人格各自对应一个独立渠道（`qq-group-<hash>`），所以同一个群换人格等于换会话：旧对话留在旧人格的会话里，共享事实（facts）仍然延续。
- 单个人格不存在时，保存会被拒绝；如果人格后来被删掉，运行时会回退到默认人格并写一条警告日志。
- 关键词接话按“该群人格”的名字生成，不再是全局同一套简称；设置页会列出每个人格的自动关键词。

## 两种模式

| 模式 | 行为 |
| --- | --- |
| `mention` | 只有被 @ 时才回复，其余消息只留在内存里作为上下文。 |
| `active` | 被 @ 时照常回复；普通消息会进入“要不要自己插话”的判断。 |

“主动参与”不是每条都回，而是在群消息安静下来后按设置判断一次：

- 至少要有 `minMessages` 条新消息（相对她上次发言之后）；
- 过了 `debounceSec` 秒的安静期；
- 不在免打扰时段；
- 与上次主动发言间隔超过 `cooldownMin` 分钟；
- 当天主动次数未超过 `dailyLimit`；
- 按 `probability` 掷一次概率。

判断轮使用群自己的会话（含群里 @ 过她的往来），并以该群配置的人格运行；判断指令只提供最近 `contextSize` 条缓存消息，不会写进聊天历史；她要么调用 `qq_group_chime` 真正发言，要么调用 `qq_group_hold` 明确不说话。两条路径都不会把“内心判断”的正文留在群会话里。

> 主动发言需要群内工具权限为 `full`；`off` 时只保留 @ 自动回复，不会触发判断轮。

## 群友标签与关键词接话

设置页的“群友与标签”会列出当前白名单群的成员（QQ 号、昵称、群名片），可以给每个人写一条本地标签，例如“群主”“小幽的鱼”“现实朋友”。标签保存在插件数据目录的 `tags.json`，不写回 QQ，也不会上传；当前人格读群成员或群消息时会看到标签，标签只作为资料，不是系统指令。她也可以调用 `qq_group_tag_member` 自己写或清除标签。

关键词接话默认开启：设置页可以开关、设置最短间隔（默认 15 秒），还可以追加额外关键词。自动关键词由该群人格的名字生成，例如“周小迟”会得到“周小迟”“小迟”“迟宝”；不同人格的群按各自的名字生成。群里有人提到这些词时，即使没有 @ 她，也会触发一次正常回复；仍受最短间隔和群规则限制，不会无限刷屏。

## 群正文保留范围

- 普通群消息只进入插件内存里的最近缓存，用于判断和接话；不写 `state.json`，也不写入个人记忆。
- 被 @ 的那条消息会进入该群对应的独立群会话，之后按宿主的会话历史策略保留；这部分是群会话历史，不是个人记忆。
- `qq_group_read` 和 `qq_group_list` 的 `includeRecent` 使用宿主的临时工具结果：原文只在当前工具轮可见，持久回执只保存群号、条数、模式等摘要，不保存群正文。
- 临时工具结果依赖宿主 `0.1.1` 的 `tools.registerTransient`；更老的宿主会退回普通工具结果，此时不能保证“原文只在当轮可见”。
- 群友标签保存在插件数据目录的 `tags.json`，只作为资料，不会被当成系统指令，也不会写回 QQ。

## 群语音

群语音依赖 `说话` 插件（`voice`）提供合成能力，未接入时不会影响文字回复。

- 触发方式二选一：每发 `N` 条文字回复后发 1 条语音，或每隔 `N` 分钟发 1 条语音。
- 发送方式：`文字后追加一条语音`（默认）或 `用语音替换这条文字`（只对不超过语音文本上限的短文生效）。
- `两条语音最短间隔` 用来防止连续刷语音；`语音文本上限` 控制朗读长度，超出会截到最近的句号/逗号。
- 语音由当前默认音色实时合成；合成或平台发送失败时，本条自动退回文字，不会卡住回复。
- 设置页的“尝试发一句”可以选择一个白名单群，立即发一条测试语音；测试不进自动语音计数，也不会写入群聊上下文。
- 群语音会计入“今日主动”次数，并在设置页状态里显示“今日语音 / 待语音”计数。

## 工具

- `qq_group_list`：查看已接入的群、模式、所用的人格、缓存条数、今日主动次数，可选附带最近消息；最近消息里的非自己发言会带 `messageId`。
- `qq_group_members`：读取白名单群的成员列表；返回 QQ 号、群名片、昵称、标签，并标记“是不是自己”和“名字里是否带鱼”，可按昵称/名片/QQ 号过滤。
- `qq_group_tag_member`：给某个真实群成员写一条本地标签（最多 80 字），留空清除；标签只作为资料给当前人格看，不是指令。
- `qq_group_read`：读取某个群最近缓存的群消息；非自己发言会带 `messageId`，可直接用于引用。
- `qq_group_say`：在普通对话、私聊或自主任务里主动去群里说一句（需要 `full` 权限）；可用 `atUserIds` @ 最多 3 个本群真实成员，也可用 `replyTo` 引用本群某条消息的 `messageId`。
- `qq_group_image`：把图库图片发到群里，可带一句配文（需要 `full` 权限和图库接入）；一次最多 8 张，只有 `status=sent` 且 `confirmed=true` 才算发送成功。
- `qq_group_chime`：只用于群聊自主判断轮，真正把话发到群里（临时工具，参数不落盘）；同样可用 `atUserIds` @ 最多 3 个本群真实成员，也可用 `replyTo` 引用群友消息。
- `qq_group_hold`：只用于群聊自主判断轮，明确选择不发言。

## 其他行为

- 被 @ 时直接回复，不再额外 @ 发言人；回复会引用触发她的那条群消息，戳一戳不引用。主动发言默认不带 @，需要时可用 `atUserIds` 指定最多 3 个本群真实成员；要引用别人说的话，用 `qq_group_read` 取 `messageId`，再传给 `qq_group_say` / `qq_group_chime` 的 `replyTo`。
- 群里的“戳一戳”默认会回应：只有戳她本人时才算，戳别人不回应；可在设置里关掉，关掉后只记录、不回复。群戳依赖 QQ 主插件转发 `notice/poke` 事件。
- 回复成功后开启“继续对话”窗口（默认 10 秒，以秒计时，可设 0–86400，0 关闭）：这段时间里，刚被回复的同一个人继续发消息，即使不 @ 她，也会被当成接着聊并正常回复；换人则不自动接话。
- 群消息提到该群人格的名字/简称时也会主动接话（默认开启）：自动关键词按该群人格名字生成，设置页可关闭、调整最短间隔或追加关键词；触发后同样走正常回复和引用逻辑。
- 群成员名字里带“鱼”的视为其他鱼，不是普通群友。她也可以在 `qq_group_say` / `qq_group_chime` 里用 `atUserIds` 指定本群任意真实成员的 QQ 号来 @ 并聊天，最多 3 个；不能 @ 机器人自己，也不能编造不在群里的号。最近消息里出现 @ 时仍会标注对方名字和“〔鱼〕”；需要辨认群友时先调用 `qq_group_members` 读取成员列表。
- 默认只把“@你本人”算作被叫；`@全体成员` 只作为群消息记录，不回复。需要回应群公告式 @ 时，打开设置里的“被@全体成员时也回复”。
- 长回复按“单条分段字数”切分发送，段间沿用 QQ 插件的最小发送间隔。
- 默认开启“按空行拆分段落”：一个回复里有几段，就分成几条依次发送；最多分为“最多分为几条”配置的数量，超出的段落会合并。关掉该开关则只按字数切分。
- 分段前先跑“分段保护正则”：命中的段落保持完整、不拆开，其余段落仍按空行正常分段；整条没有分段点时才会一次性发出（超过单条平台上限 4000 字才强制按字数切）。默认覆盖全角/半角括号、书名号、直角引号与中英文引号，可在设置里改或留空关闭。
- 群消息只缓存在内存（每组最多 2×`contextSize` 条），插件重启后清空；群号、模式和主动发言计数会持久化。
- QQ 离线时不会发送；工具返回“未发送/不确定”时不要换 `actionId` 重发，先核对回执。

## 依赖

`qq` 插件提供 `registerGroupReceiver` / `sendGroupText` / `sendGroupMedia` / `listGroups` / `groupStatus`（`groupApiVersion: 1.0.0`）；`sendGroupText` 支持 `atUserIds` 和 `replyTo`（引用群消息）。`sendGroupMedia` 现支持 `text` / `image` / `voice`（OneBot `record` 段）。群语音可选依赖 `voice` 插件；本插件安装在 `plugins/qq/sub/group`，由 `qq` 的 `plugin.yaml` 通过 `sub: [qzone, group]` 自动挂载。
