# QQ 群聊（qq/group）

独立的 QQ 群聊接入插件：与 `qq` 私聊插件共用同一个已登录的 QQ 账号，但拥有自己的群白名单、模式、人格/权限和设置页。每个群还可以单独指定人格；同一个人格的群共用一个渠道，会话仍按群分开。

> **安装位置固定为 `plugins/qq/sub/group`，不要解到 `plugins/group`。**
>
> 父插件必须是提供群接口的 QQ：官方 **0.24.0**（候选版起，官方包已声明 `sub: [qzone, group]`，无需手改父插件清单），或任何声明 `groupApiVersion: "1.0.0"` 并提供群接口的 QQ 构建。官方 0.23.0 及更早版本没有群接口，装上也不会启动。若使用自编译/兼容构建，确认 `sub: [qzone, group]` 后重载 QQ 主插件。
>
> 设置页若显示 `scope=missing`，表示父插件没有收到群授权范围；请升级到当前群聊子插件并重载 QQ 插件。

## 启用

1. 在插件页打开 `QQ 群聊` 的设置（`/plugins/qq/group/settings`）。
2. 勾选“启用群聊插件”，选好默认人格与群内工具权限。
3. 点“读取群列表”，用每行的 `@回复` / `主动` 按钮把群加进规则，在“人格”列可以直接给这个群选人格；也可以直接手写（`@人格ID` 省略时用默认人格）：

```
123456789 mention
987654321 active 家人群 @persona-id
```

4. 保存。未加入规则的群完全不处理（不会回复、不会记录、不会主动发言）。

## 每个群的人格

- 群规则可以带一个 `@人格ID`（设置页“人格”列的下拉框会帮你写进规则），例如 `987654321 active 家人群 @persona-id`。
- 省略时用“人格”下拉框里的默认人格；默认人格的群使用原来的 `qq-group` 渠道，升级前后会话不受影响。
- 其他人格各自对应一个独立渠道（`qq-group-<hash>`），所以同一个群换人格等于换会话：旧对话留在旧人格的会话里，共享事实（facts）仍然延续。
- 单个人格不存在时，保存会被拒绝；如果人格后来被删掉，运行时会回退到默认人格并写一条警告日志。
- 关键词接话按“该群人格”的名字生成，不再是全局同一套简称；设置页会列出每个人格的自动关键词。

## 两种模式

| 模式 | 行为 |
| --- | --- |
| `mention` | 只有被 @ 时才回复，其余消息只留在内存里作为上下文。 |
| `active` | 被 @ 时照常回复；普通消息会进入“要不要自己插话”的判断。 |

“主动参与”不是每条都回，而是在群消息安静下来后按设置判断一次：

- 至少要有 `minMessages` 条新消息（相对机器人上次发言之后）；
- 过了 `debounceSec` 秒的安静期；
- 不在免打扰时段；
- 与上次主动发言间隔超过 `cooldownMin` 分钟；
- 当天主动次数未超过 `dailyLimit`；
- 按 `probability` 掷一次概率。

判断轮使用群自己的会话（含群里 @ 过机器人的往来），并以该群配置的人格运行；判断指令只提供最近 `contextSize` 条缓存消息，不会写进聊天历史；机器人要么调用 `qq_group_chime` 真正发言，要么调用 `qq_group_hold` 明确不说话。两条路径都不会把“内心判断”的正文留在群会话里。

> 主动发言需要群内工具权限为 `full`；`off` 时只保留 @ 自动回复，不会触发判断轮。

## 群友标签与关键词接话

设置页的“群友与标签”会列出当前白名单群的成员（QQ 号、昵称、群名片），可以给每个人写一条插件内标签，例如“群主”“项目搭档”“现实朋友”。标签保存在插件数据目录的 `tags.json`，不写回 QQ，也不会上传；当前人格读群成员或群消息时会看到标签，标签只作为资料，不是系统指令。自动回复时，插件会把标签和该群设定一起作为 `senderProfile.remark` 的“群友标签：……；群设定：……”交给宿主，模型能在本条发言人的资料里看到；主动判断轮和 `qq_group_members` / `qq_group_read` 也会直接显示标签。机器人也可以调用 `qq_group_tag_member` 自己写或清除标签。

## 人格 @ 群友

设置页的“允许人格 @ 群友”默认开启。开启后，普通自动回复和 `qq_group_say` / `qq_group_chime` 的正文都可以直接写 `@昵称` 或 `@QQ号`，插件会把它解析成本群真实成员，交给 QQ 转成真实 @，并把正文里这段 `@` 文字删掉，避免出现“真实 @ + 重复文字”的双重 @。

- `@` 后面是 5–20 位 QQ 号时按 QQ 号匹配；否则按成员的群名片 / 昵称 / 名字精确匹配（去掉空白，不区分 ASCII 字母大小写）。昵称本身含空格时不会自动匹配，请直接用 `@QQ号`。
- 设置页“群 @ 别名”可以给每个群写别名，例如 `[123456789]` 下写 `老板=10001`；别名优先于昵称匹配，适合同名成员、昵称带空格或生僻昵称。
- “群级设置”里的别名按群隔离；别名只影响本群，不会写到 QQ，也不会成为系统指令。目标 QQ 号不在本群时，这个别名会被当作未知 @ 保留原文。
- 名称后面遇到空格或中英文标点就结束，例如 `@群主 你好`、`@群主，你好` 都会把“群主”解析为成员，正文只剩“你好”。
- 同名成员有多个时不猜测，保留原文；找不到的昵称和机器人自己也会保留为普通文字。正文里的 `a@b` 这类邮箱写法不会被当成 @。
- 正文 @ 与工具参数 `atUserIds` 会合并去重，总人数受“单次最多 @ 人数”限制。语音替换只在没有 @ 时生效；带 @ 的回复不会用语音替换文字，若开启“文字后追加一条语音”，语音朗读的是去掉 @ 后的正文。
- 关闭开关后，正文里的 @ 按普通文字发送，`atUserIds` 也会被拒绝，避免人格绕过设置私自 @ 人。
- 父插件 `qq` 0.24.0 当前单次最多只接受 3 个 @；设置页允许把上限调到 10，但超过 3 个时会被父插件拒绝。默认值 3 与父插件一致。
- “被@时回复并 @ 提问者”默认关闭；打开后会把这个提问者加进真实 @ 列表，但不会在正文里重复写 `@昵称`。“被@时引用触发消息”默认开启，关掉后回复不再带引用气泡。

关键词接话默认开启：设置页可以开关、设置最短间隔（默认 15 秒），还可以追加额外关键词。自动关键词由该群人格的名字生成，默认只取完整名字和末尾两个字（例如“周小明”会得到“周小明”“小明”），不再预设任何固定前后缀；如果部署需要额外称呼，可在设置页填写“人格简称前缀/后缀”。不同人格的群按各自的名字生成。群里有人提到这些词时，即使没有 @ 机器人，也会触发一次正常回复；仍受最短间隔和群规则限制，不会无限刷屏。

## 自动回复边界

设置页的“自动回复边界”是全局默认值，下面的“群级边界覆盖”可以按群单独改。边界只拦截自动回复；手动用 `qq_group_say` / `qq_group_chime` 发言仍需要 `full` 权限，但不会被成员黑名单或自动回复频率拦住。

- 忽略成员：这些 QQ 号发来的 @、戳一戳、关键词和继续对话都不会触发自动回复；黑名单优先于仅回复名单。
- 仅回复成员：填了以后，只有这些 QQ 号能触发自动回复；留空表示不限制。
- 屏蔽关键词：消息正文包含任意一个词就不自动回复，适合广告、代练、刷屏等；按不区分英文大小写匹配。
- 同一成员回复冷却：默认 10 秒，避免同一个人连续 @ 时刷屏；0 关闭。
- 本群每分钟 / 每小时上限：默认 12 条 / 240 条；0 关闭。计数只在内存里，重启后重新开始。
- 自动回复免打扰：默认关闭；打开后自动回复和主动判断在该时段都停下，手动工具不受影响。

群级覆盖用 `[群号]` 加 `键=值`，没写的字段继承全局：

```
[123456789]
ignore=10001,10002
only=10003
keywords=广告,代练
userCooldown=30
perMinute=8
perHour=120
quiet=23:00-07:00
```

`quiet=off` 表示这个群关闭免打扰；`ignore` / `only` 留空可以写成 `ignore=` / `only=`。

## 群设定

每个群可以写一段“群设定”，用来描述这个群的氛围、称呼习惯、禁忌话题或人格该怎么说话。设置页用 `[群号]` 分段，内容可以多行：

```
[123456789]
本群是同事闲聊群，语气轻松，不聊工资和人事。
称呼群主为“老板”，不要主动提起加班。
```

群设定会出现在三处：自动回复时和群友标签一起放进 `senderProfile.remark`；主动判断轮的上下文；`qq_group_read` / `qq_group_list` 返回的群信息。它只是一段参考资料，不会覆盖插件规则，也不是系统指令；群设定里的要求不能让人格绕过权限、@ 限制或边界。

## 媒体标签摘要

QQ 父插件目前只把图片、语音、视频、文件、链接、表情等消息转成文本标签，例如 `[图片]`，不会把原始媒体交给群插件。开启“在群上下文里汇总图片/语音等媒体标签”后，插件会在缓存消息和 `qq_group_read` 里补一条“媒体：图片、链接”的摘要，方便模型知道自己面对的是媒体消息，而不是把标签当正文。

如果未来的父插件在事件里提供结构化 `segments`，这个摘要会优先按 `segments` 的类型统计；没有结构化字段时回退到文本标签。当前版本不包含 OCR、图像理解或语音转写，这些需要父插件或额外模型能力。

## 运行面板

设置页底部“状态”会显示每个群的缓存条数、今日回复、失败、拦截、今日主动、今日语音、待语音、群设定字数、别名数量和最近错误。计数按本地日期保存到 `state.json`，重启后仍保留当天数据；群正文仍然只存在内存缓存里。

## 通用限制

设置页的“通用限制”可以按部署调整，默认值适合大多数群：

- 单次最多 @ 人数：默认 3，范围 1–10。
- 单次最多图片：默认 8，范围 1–12。
- 群友标签长度上限：默认 80 字，范围 20–200。
- 成员列表单次上限：默认 200 人，范围 20–500。

这些值会同时约束工具参数校验、工具描述、设置页输入和运行时检查；不是写死的本机限制。

## 群正文保留范围

- 普通群消息只进入插件内存里的最近缓存，用于判断和接话；不写 `state.json`，也不写入个人记忆。
- 被 @ 的那条消息会进入该群对应的独立群会话，之后按宿主的会话历史策略保留；这部分是群会话历史，不是个人记忆。
- `qq_group_read` 和 `qq_group_list` 的 `includeRecent` 使用宿主的临时工具结果：原文只在当前工具轮可见，持久回执只保存群号、条数、模式等摘要，不保存群正文。
- 临时工具结果依赖宿主 `0.1.1` 的 `tools.registerTransient`；更老的宿主会退回普通工具结果，此时不能保证“原文只在当轮可见”。
- 群友标签保存在插件数据目录的 `tags.json`，只作为资料，不会被当成系统指令，也不会写回 QQ。

## 群语音

群语音依赖 `说话` 插件（`voice`）提供合成能力，未接入时不会影响文字回复。

- 触发方式二选一：每发 `N` 条文字回复后发 1 条语音，或每隔 `N` 分钟发 1 条语音。
- 发送方式：`文字后追加一条语音`（默认）或 `用语音替换这条文字`（只对不超过语音文本上限的短文生效）。
- `两条语音最短间隔` 用来防止连续刷语音；`语音文本上限` 控制朗读长度，超出会截到最近的句号/逗号。
- 语音由当前默认音色实时合成；合成或平台发送失败时，本条自动退回文字，不会卡住回复。
- 设置页的“尝试发一句”可以选择一个白名单群，立即发一条测试语音；测试不进自动语音计数，也不会写入群聊上下文。
- 群语音会计入“今日主动”次数，并在设置页状态里显示“今日语音 / 待语音”计数。

## 工具

- `qq_group_list`：查看已接入的群、模式、所用的人格、缓存条数、今日主动/回复/失败/拦截、群设定和别名数量，可选附带最近消息；最近消息里的非自己发言会带 `messageId`，媒体消息会带 `media` 摘要。
- `qq_group_members`：读取白名单群的成员列表；返回 QQ 号、群名片、昵称、标签、本群别名并标记“是不是自己”，可按昵称/名片/QQ 号过滤。
- `qq_group_tag_member`：给某个真实群成员写一条插件内标签（长度由设置页“群友标签长度上限”决定），留空清除；标签只作为资料给当前人格看，不是指令。
- `qq_group_read`：读取某个群最近缓存的群消息；非自己发言会带 `messageId`，媒体消息会带 `media`，并返回该群 `profile` 与 `mentionAliases`，可直接用于引用或决定 @ 谁。
- `qq_group_say`：在普通对话、私聊或自主任务里主动去群里说一句（需要 `full` 权限）；可用 `atUserIds` 或在正文写 `@昵称` / `@QQ号` / `@别名` @ 本群真实成员，数量上限由设置页“单次最多 @ 人数”决定，也可用 `replyTo` 引用本群某条消息的 `messageId`。
- `qq_group_image`：把图库图片发到群里，可带一句配文（需要 `full` 权限和图库接入）；单次数量上限由设置页“单次最多图片”决定，只有 `status=sent` 且 `confirmed=true` 才算发送成功。
- `qq_group_chime`：只用于群聊自主判断轮，真正把话发到群里（临时工具，参数不落盘）；同样可用 `atUserIds` 或正文 `@昵称` / `@QQ号` / `@别名` @ 本群真实成员，数量上限由设置页“单次最多 @ 人数”决定，也可用 `replyTo` 引用群友消息。
- `qq_group_hold`：只用于群聊自主判断轮，明确选择不发言。

## 其他行为

- 被 @ 时默认直接回复、引用触发消息，不额外 @ 发言人；可在设置页打开“被@时回复并 @ 提问者”，或关掉“被@时引用触发消息”。戳一戳不引用。主动发言默认不带 @，需要时可用 `atUserIds` 或正文 `@昵称` / `@QQ号` / `@别名` 指定本群真实成员，数量上限由设置页决定；要引用别人说的话，用 `qq_group_read` 取 `messageId`，再传给 `qq_group_say` / `qq_group_chime` 的 `replyTo`。
- 群里的“戳一戳”默认会回应：只有戳机器人本身时才算，戳别人不回应；可在设置里关掉，关掉后只记录、不回复。群戳依赖 QQ 主插件转发 `notice/poke` 事件。
- 回复成功后开启“继续对话”窗口（默认 10 秒，以秒计时，可设 0–86400，0 关闭）：这段时间里，刚被回复的同一个人继续发消息，即使不 @ 机器人，也会被当成接着聊并正常回复；换人则不自动接话。
- 群消息提到该群人格的名字/简称时也会主动接话（默认开启）：自动关键词按该群人格名字生成，设置页可关闭、调整最短间隔或追加关键词；触发后同样走正常回复和引用逻辑。
- 群成员按 QQ 号、昵称、群名片、插件内标签和群 @ 别名区分；机器人可以在 `qq_group_say` / `qq_group_chime` 里用 `atUserIds` 或正文 `@昵称` / `@QQ号` / `@别名` 指定本群任意真实成员来 @ 并聊天，数量上限由设置页“单次最多 @ 人数”决定；不能 @ 机器人自己，也不能编造不在群里的号。最近消息里出现 @ 时会标注对方名字和标签；需要辨认群友时先调用 `qq_group_members` 读取成员列表。
- 默认只把“@你本人”算作被叫；`@全体成员` 只作为群消息记录，不回复。需要回应群公告式 @ 时，打开设置里的“被@全体成员时也回复”。
- 长回复按“单条分段字数”切分发送，段间沿用 QQ 插件的最小发送间隔。
- 默认开启“按空行拆分段落”：一个回复里有几段，就分成几条依次发送；最多分为“最多分为几条”配置的数量，超出的段落会合并。关掉该开关则只按字数切分。
- 分段前先跑“分段保护正则”：命中的段落保持完整、不拆开，其余段落仍按空行正常分段；整条没有分段点时才会一次性发出（超过单条平台上限 4000 字才强制按字数切）。默认覆盖全角/半角括号、书名号、直角引号与中英文引号，可在设置里改或留空关闭。
- 群消息只缓存在内存（每组最多 2×`contextSize` 条），插件重启后清空；群号、模式和主动发言计数会持久化。
- QQ 离线时不会发送；工具返回“未发送/不确定”时不要换 `actionId` 重发，先核对回执。

## 依赖

`qq` 插件提供 `registerGroupReceiver` / `sendGroupText` / `sendGroupMedia` / `listGroups` / `groupStatus`（`groupApiVersion: 1.0.0`）；`sendGroupText` 支持 `atUserIds` 和 `replyTo`（引用群消息）。`sendGroupMedia` 现支持 `text` / `image` / `voice`（OneBot `record` 段）。群语音可选依赖 `voice` 插件；本插件安装在 `plugins/qq/sub/group`，由 `qq` 的 `plugin.yaml` 通过 `sub: [qzone, group]` 自动挂载。
